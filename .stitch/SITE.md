# ECHOFORM — Site Vision & Architecture Roadmap

## 1. Vision & Concept
ECHOFORM is an experimental audiovisual festival in Bengaluru, India (18—19 SEP 2027). The website bridges interactive digital-art installation and cinematic festival campaign under the theme "SOUND TAKES FORM."

## 2. Stitch Project Information
- **Project Name:** ECHOFORM Landing Experience
- **Device Target:** Desktop & Mobile responsive
- **Theme:** Dark Void / Titanium / Spectral Laser
